Method

Teams start using their Claude licences once they have practised on their own projects.

  1. 01

    Train on the team’s own work

    I build each session around documents the team already produces, such as stage reports, specifications and meeting minutes. In a typical exercise Claude pulls the key points out of all three, and someone from the team checks the summary before it is shared.

  2. 02

    Collect the questions people ask

    During training people ask questions such as “Can it compare these two specs?” and “Where did I solve this before?” Grouped together, those questions point to the tools worth building, for example a document reviewer or an assistant that searches past projects.

  3. 03

    Build in short loops with the people who will use it

    I study the existing process, redesign the workflow and build a prototype. Each version goes to the team for testing, and I revise it until it fits their daily work.

Services

Four ways to start

Each engagement is sized for one team. Pick the one that matches how much you already know about the problem.

  1. 01

    Claude training programme

    Choose this when your team has Claude licences that few people use.

    I survey the team and interview its leaders to set a baseline, then run a training day and three practical labs built on the team’s real work. Office hours and workflow clinics follow, with short surveys to track progress.

    Your team keeps the written workflows and guidance, the baseline survey to re-run later, and the exercises from the three labs.

  2. 02

    Workflow diagnostic

    Choose this when a workflow is slow and you need to find where the time goes.

    I interview the people doing the work, map one or two workflows and estimate the value of changing them.

    You get a map of the current process, a ranked list of opportunities and a recommended plan.

  3. 03

    Prototype sprint

    Choose this when you already know which task you want to fix.

    I build one tool for one task, with data and users we agree at the start, then test it against a measure we set together.

    You get a working prototype like MaterialScan or the Southwark Retrofit Atlas, an evaluation against the agreed test and a decision to scale it or stop.

  4. 04

    Embedded architect or engineer

    Choose this when a larger team has a steady stream of workflows to improve.

    An architect or engineer from my team works inside yours two or three days a week and runs the build loop from Method on one workflow at a time.

    Your team keeps the tools, and the people who tested them learn to run them.

If none of the four fits, describe the problem in one email.

Design · BIM model queries

ModelChat answers plain-English questions about a BIM model

The problem

Getting an answer out of a BIM model usually needs a specialist and a desktop licence.

What I built

I built a browser BIM viewer with a Claude chat panel. Claude answers by calling a fixed set of 14 tools: six query the model index for storeys, categories, spaces, properties and quantities, and eight act in the viewer to isolate, highlight, section and frame elements.

The test model is a timber office from the NordicLCA project, exported from Revit as IFC4 with 10,609 entities on ten IFC storeys from sea level to roof.

Tools and data

  • Three.js
  • web-ifc
  • Claude Code

Win work · Bid intelligence database

GrowthSignal collects public tenders and programmes into one database

The problem

Opportunities are spread across hundreds of procurement portals, development bank registers and news sources, so teams often find them late.

What I built

I built a self-hosted database of tenders, programmes, deals and news from more than 270 public sources, from UK, European and US portals to development banks and open-contracting feeds. Its world map holds 57,840 records. CPV codes and keywords sort records into six construction sectors, Claude tags each record’s stage, value and location, and a daily briefing summarises new and changed opportunities.

Records are ranked on sector fit, project stage, value and corroborating sources against the firm’s own target sectors, stages and countries. Search combines keywords with local embeddings across every table.

Tools and data

  • Next.js
  • SQLite with sqlite-vec
  • Claude

Win work · Live project search

Strategic Project Discovery searches live procurement sources

The problem

Business development teams check the same procurement portals by hand, one sector at a time, and notices still slip through.

What I built

I built a single web page that runs a live search across up to 676 procurement sources in 36 categories. Each result is plotted on a world map with a fit assessment for sector, scale and geography, an estimated win probability and a one-line verdict.

It needs no server or database. The hosted version opens in demo mode with fictional opportunities, and a Gemini API key switches it to live searches.

Tools and data

  • Leaflet
  • Gemini with Google Search

Design · Energy modelling

Reference Buildings Explorer shows energy model results in 3D

The problem

Energy model results sit in spreadsheets and HTML reports that are hard to compare across building types and climates.

What I built

I built an explorer for the US Department of Energy commercial reference buildings. It covers 16 building types in 16 climate locations, with their EnergyPlus geometry and simulation results in six interactive 3D views.

The whole explorer is one self-contained HTML file.

Design · Material compliance

MaterialScan checks a material palette against LBC, WELL and the client brief

The problem

Certification evidence for each product sits in spreadsheets, PDFs and email, so nobody can see the state of the whole palette.

What I built

I built a compliance dashboard for an anonymised lab and workplace project. It scores all 42 products against Living Building Challenge 4.1 imperatives I07 and I12, WELL v2 features X07 and X08 and section 2.2 of the client brief, and shows the standard text beside every verdict.

Each verdict links to the EPDs, HPDs and Declare labels behind it. An open-gaps page ranks the documents still outstanding, such as VOC test reports, corrected HPDs and Red List attestations, and gives each request a next action.

Tools and data

  • Python site generator
  • Static HTML
  • Claude Code

Deliver · Document workbench

WorkNodesCanvas turns source documents into client decks and reports

The problem

Turning surveys, workshop notes and meter data into client documents takes hours of copying and rewriting.

What I built

I built a canvas with three kinds of node. Reference nodes preview PDFs, images, Markdown, Office files and web pages. Analysis nodes send an objective and the wired references to Claude. Presentation nodes turn the analyses into a PPTX deck, a DOCX report or an HTML page.

Each analysis node names its inputs with tags such as R-101, so the sources behind every answer stay visible.

Tools and data

  • Python helper
  • Vanilla JavaScript
  • Claude Code

Portfolio · Housing retrofit

Southwark Retrofit Atlas ranks 149,062 homes by retrofit priority

The problem

Portfolio owners need to know which homes to retrofit first, what it will cost and how far a fixed budget goes.

What I built

I built an atlas that joins the GLA building stock model, the national EPC register and ONS boundaries. It costs a retrofit package for each of Southwark’s 149,062 homes and ranks them on carbon, need and deliverability. Changing the budget or a weighting re-ranks every home in under a second.

The analysis finds 56,873 homes below EPC C, and 86% of them can reach it for a median cost of £5.8k. At the default weights a £47.0m budget, net of grant, funds 4,079 homes and saves 6.6 kt of CO₂e a year. Raising the carbon weight to 45 funds 4,160 homes and saves 7.1 kt. It also checks 7,045 commercial buildings against the minimum energy efficiency standard.

Tools and data

  • D3
  • Canvas map
  • GLA LBSM 2
  • MHCLG EPC register
